# Gridiron

Football on the TV; your phone is the ball. Throw it (don't let go!) to
pass to receivers on the big screen. Touchdown Pass, the Two-Minute Drill
and Holy War (BYU phones vs Utah phones). Made for a BYU–Utah watch party.

Open `web/index.html` on the TV, scan the QR code with phones. See
`HANDOFF.md` for how it works and `CLAUDE.md` for the checks.
